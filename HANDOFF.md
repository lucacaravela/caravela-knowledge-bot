# HANDOFF — Caravela Knowledge Bot

Context file for anyone (human or LLM assistant) picking up this project.
Written 2026-07-24, at the completion of v1. Read this before touching code.

## What this is

Internal knowledge chatbot for Caravela Capital (early-stage LatAm VC).
The investment team asks questions in Portuguese or English — about
companies in the dealflow, pass reasons, sectors, the portfolio, people,
and internal documents — and the bot answers by querying **Affinity CRM**
and **Google Drive live** (no sync jobs, no vector store), synthesizing
with the Claude API. Two channels share all logic: a Streamlit web app and
a WhatsApp bot.

## Architecture (one paragraph)

`agent.py` runs a Claude tool-use loop (model `claude-sonnet-4-6`, max 25
tool calls/question) over tools implemented in `affinity.py` and
`drive.py`. `app.py` (Streamlit, Google OIDC login) and `whatsapp_app.py`
(FastAPI webhook, Twilio sandbox today / Meta Cloud API later) are thin
channel layers over the same loop. `storage.py` persists chat history to
Supabase (PostgREST via `requests`), private per user. Every tool returns
a readable error string instead of raising, so one failure never kills an
answer. `auth_secrets.py` generates `.streamlit/secrets.toml` from env
vars at startup (Streamlit auth can't read env vars directly).

## External services and non-obvious facts

**Affinity** (the CRM — key quirks discovered the hard way):
- Two APIs, same key: v1 (`https://api.affinity.co`, HTTP Basic with EMPTY
  username, key as password) has notes + name search; v2 (`/v2`, Bearer)
  has companies, lists, fields.
- v2 `fieldTypes` param accepts ONLY `enriched`, `global`,
  `relationship-intelligence`. Passing `list` returns 400. List-scoped
  fields come via list-entry endpoints with `fieldIds`.
- Dealflow = list "Pipeline" id **31953** (~8.7k entries, API returns
  newest first). Portfolio = list "Investidas" id **73539**.
- Field ids: Setor=`field-394528` (Portuguese dropdown: 'Saúde',
  'Fintech', 'Logística'…), Status=`field-278853` ('Pré-pipe', 'Deep
  Dive', 'Termsheet', 'Won', 'Pass'…), Owners=`field-278854`, Motivo
  lost=`field-316106`, Descrição=`field-446059`, Blurb=`field-3206378`.
- Pass rationale lives in COLUMNS, not notes: 'Motivo lost' (categories)
  and 'Motivo Pass Detalhado' (full text, a global field).
- `search_pipeline` scans max 3000 entries (≈ back to Jan 2025) with a
  15-min in-process cache; the `keyword` param matches name+description
  columns (accent-insensitive) — the way to answer sub-sector questions
  ("crossborder fintechs").
- Known CRM data issues: Celes exists twice (biai.tech = main entry,
  celes.ai = secondary); Allie is duplicated in Investidas.

**Google Drive**: service account (JSON in `GOOGLE_SERVICE_ACCOUNT_JSON`
or a file path in `GOOGLE_SERVICE_ACCOUNT_FILE`), read-only. The bot only
sees what is explicitly shared with the service-account email. Full-text
search across shared drives; reads Docs/Slides (text export), Sheets
(CSV), .xlsx (openpyxl), PDFs (pypdf). Image-based PDFs (designed pitch
decks) have no extractable text — the bot says so honestly. Exports are
UTF-8 with BOM (`resp.encoding = "utf-8-sig"` matters).

**Supabase** (persistent chats): project ref `xgicphpwbkfzshwtrfkj`,
São Paulo. Tables `conversations`, `messages`, `phone_mappings` (schema
in git history / recreate via dashboard). Access ONLY from the backend
with the secret key; privacy = every query filters by the login email.
Conversation titles are generated by a one-shot Haiku call
(`agent.make_conversation_title`, falls back to truncated question).
WhatsApp phones must be in `phone_mappings` (digits only, include the
Brazilian variant WITHOUT the extra 9) for durable history; unmapped
phones get in-memory history only.

## Cost containment (do not undo these)

- Prompt caching: system+tools cached; a moving `cache_control` marker on
  the latest tool_result caches the loop's growing context.
- History compaction (`agent.compact_history`): after each answer, raw
  tool traffic is dropped; only questions + final answers persist.
- Context cap (`agent.trim_history`): max 40 messages sent per question
  regardless of conversation age.
- Typical question ≈ US$0.02–0.08; heavy census questions ≈ $0.30–0.60.
- Style rules live in the system prompt: concise, objective, no emojis,
  cite sources, state explicitly when a column/info is empty or missing.

## Known gaps / next work (priority order)

1. `/twilio-webhook` does NOT validate `X-Twilio-Signature` (Meta endpoint
   does validate). Spoofing = token burn, not data leak. Fix planned.
2. Two rapid WhatsApp messages from one phone race (parallel agent runs on
   the same conversation). Needs a per-phone queue/lock.
3. `affinity._pipeline_cache` is not thread-locked — concurrent sector
   questions can duplicate page fetches/entries.
4. Meta business verification → production WhatsApp switch (see above).
5. Starter upgrade for `caravela-whatsapp-bot` + render.yaml sync.
6. Backlog: vision/OCR for image PDFs; `search_past_answers` tool over
   stored conversations; deeper pipeline scan; weekly digest.
